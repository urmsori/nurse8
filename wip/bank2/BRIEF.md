# 기본 문제 다시 쓰기: 공통 지침

한국 지방공무원 간호직 필기시험 학습 앱(/home/user/nurse8)의 기본 문제 은행을 **실제 기출과 닮게** 다시 만든다. 실제 기출을 분석해 보니 지금 문제는 유형과 문체가 기출과 많이 달랐다. 사용자가 다시 만들기로 정했다.

## 먼저 읽을 것
- 분석 문서: 간호 과목은 `/home/user/nurse8/docs/기출유형-간호.md`, 국어·영어·한국사는 `/home/user/nurse8/docs/기출유형-공통.md`. 네 과목의 유형 설명, 표기 관습, 목표, 문체 규칙을 그대로 따른다.
- 실제 기출(문체의 본보기): `/home/user/nurse8/src/past/<연도>-<과목 글자>.json`. 발문 표현, 상자 쓰는 법, 선지 길이와 종결 방식을 여기서 익힌다. **기출 문항을 베끼거나 숫자·낱말만 바꾼 문제를 만들지 않는다**(기출은 앱에 따로 들어 있다). 같은 개념을 물어도 발문·자료·선지는 새로 쓴다.
- 지금의 문제 은행: `/home/user/nurse8/src/bank/<과목 글자>.json`.

## 결과물
- 네가 맡은 묶음을 JSON 파일 하나로 쓴다(경로는 과제에 적혀 있다). JSON 배열, 문제 하나가 한 줄.
- 키는 정확히 `id, subj, unit, q, opts, ans, exp`.
  - `ans` 는 정답 선지의 0부터 세는 번호(0~3). `opts` 는 정확히 4개이고 ①②③④ 를 넣지 않는다. `unit` 은 12자 이내.
  - `q`: 발문. 지문·자료·사례·<보기>는 발문 뒤에 빈 줄(`\n\n`)을 두고 적는다(앱이 상자로 그린다). 줄바꿈은 `\n`. 자료가 둘이면 상자 안에서 `<지침>`, `<개요>` 같은 이름표 줄과 빈 줄로 나눈다. `q` 는 1,500자까지, 선지는 300자까지.
  - 밑줄은 `__글__`(기호가 있으면 `㉠ __글__`), 빈칸은 밑줄 6개 `______`(이름 붙은 빈칸은 `(가) ______`). ○ 항목과 ㄱ.ㄴ.ㄷ. 보기는 한 줄에 하나씩. 표는 그릴 수 없으니 줄마다 ` | ` 로 칸을 나눈 글로 쓴다.
  - 합답형은 보기 ㄱ~ㄹ을 상자에 넣고 선지를 `ㄱ, ㄴ` 꼴로 쓴다. 지문 안의 위치 표시는 (A)(B)(C)(D)를 쓴다(선지에 원문자를 쓸 수 없다).
  - `exp`: 해설 2~4문장. 정답의 근거와 나머지 선지가 틀린 이유. "첫 번째 선지"처럼 위치로 가리키지 않는다. 긴 지문 문제는 근거가 되는 지문 내용을 짚는다.
- **id 규칙**: 과제에 적힌 새 id 범위를 순서대로 쓴다. 기존 문제를 살려 쓸 때(같은 지식을 같은 정답으로 묻되 형식만 기출 꼴로 고친 경우)는 **기존 id 를 그대로 둔다**(학습 기록이 id 로 이어진다). 묻는 내용이나 정답이 달라졌으면 새 id 를 쓴다. 한 id 를 두 번 쓰지 않는다.
- 세트 문항(한 지문에 두 문제)은 같은 지문을 두 문제에 각각 넣고, 두 문제를 이어서 둔다.

## 품질
- **정확성이 가장 중요하다.** 정답은 반드시 하나이고 이견이 없어야 한다. 법령·제도는 현행 기준(오늘은 2026년 11월)으로 쓰고, 조문의 숫자·기한·주체가 들어가면 웹 검색으로 확인한다(법령 원문 사이트는 이 환경에서 안 열릴 수 있다. 조문을 인용한 검색 결과나 공공기관 안내를 쓴다). 확인이 안 되면 그 문제는 내지 않는다. 해마다 바뀌는 통계와 사업 지침은 묻지 않는다.
- 묶음 안에서 정답 위치 0~3 이 고르게 나오게 한다(차이 2 이내). 정답 선지만 유난히 길거나 구체적이지 않게 한다.
- 지문은 직접 쓴다. 저작권이 살아 있는 글을 옮기지 않는다. 지어낸 내용을 실제 통계·연구·기록처럼 쓰지 않는다.
- 15~20문제를 쓸 때마다 파일에 저장하고(중간에 끊겨도 남도록) `python3 /tmp/claude-0/-home-user-nurse8/11953438-4bd6-5835-93dd-880b3b9add7a/scratchpad/bank2/check_part.py <네 파일>` 을 돌려 형식 오류, 정답 위치, 단원 개수, 정답 선지 길이 경고를 본다.
- 다 쓴 뒤 `q` 와 `opts` 만 출력해 처음부터 다시 읽으며 답을 가리고 직접 풀어 `ans` 와 대조한다. 정답이 둘로 읽히거나 없는 문제, 해설과 어긋나는 문제를 고친다.
