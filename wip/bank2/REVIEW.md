# 새로 쓴 기본 문제 검토 지침

한국 지방공무원 간호직 필기시험 학습 앱(/home/user/nurse8)의 기본 문제를 실제 기출과 닮게 다시 쓰고 있다. 방금 다른 사람이 문제 묶음 하나를 썼다. 너는 **독립된 검토자**다. 쓴 사람은 자기가 쓴 문제를 스스로 다시 풀어 보았을 뿐이다.

## 자료
- 검토할 묶음 파일(과제에 경로가 있다): JSON 배열, 한 줄에 한 문제. 키는 id, subj, unit, q, opts, ans, exp. `ans` 는 정답 선지의 0부터 세는 번호. 밑줄은 `__글__`, 빈칸은 밑줄 6개, 지문·자료는 발문 뒤 빈 줄 다음.
- 문체의 본보기인 실제 기출: `/home/user/nurse8/src/past/<연도>-<과목 글자>.json`.
- 유형과 문체 규칙: 간호 과목은 `/home/user/nurse8/docs/기출유형-간호.md`, 국어·영어·한국사는 `/home/user/nurse8/docs/기출유형-공통.md`.

## 할 일
1. 문제마다 `ans` 를 보기 전에 먼저 직접 푼다. 짧은 스크립트로 q 와 opts 만 20문제쯤씩 나눠 출력해 **지문까지 전부** 읽고 답을 적은 뒤 `ans` 와 대조한다. 다르면 어느 쪽이 맞는지 따진다.
2. 문제마다 확인한다.
   - 정답이 정확히 하나인가. 오답 선지가 실제로는 맞는 말이거나, 정답 선지가 틀린 말은 아닌가. 지문만으로 풀리는 유형은 지문 밖 지식 없이 답이 하나로 정해지는가.
   - 사실이 정확한가(이론·학자·개념의 귀속, 연도·인물·사건, 법령의 숫자·기한·주체, 영어 문장의 문법, 계산). 조금이라도 불확실한 법령·사실은 웹 검색으로 확인한다. 법령 원문 사이트는 이 환경에서 안 열릴 수 있으니 조문을 인용한 검색 결과나 공공기관 안내를 쓴다. 확인할 수 없는 서술은 문제나 해설에서 빼거나 확실한 내용으로 바꾼다.
   - 해설이 정답과 맞고 해설 속 설명도 정확한가. 발문("옳은 것/옳지 않은 것")과 정답의 방향이 맞는가.
   - 실제 기출 문항(`src/past`)을 베끼거나 낱말만 바꾼 문제가 아닌가. 그런 문제는 다른 소재로 바꾼다.
   - 세트 문항은 두 문제의 지문이 글자 그대로 같은가.
   - 정답 선지만 유난히 길거나 구체적이어서 답이 드러나지 않는가.
3. 오류나 모호함을 찾으면 그 파일에서 직접 고친다. 가능하면 최소로 고치고, 살릴 수 없으면 같은 유형·단원의 다른 문제로 바꿔 쓴다(id 유지). id, 문제 수, 형식은 바꾸지 않는다. 정답 위치 분포가 크게 쏠리지 않게 한다.
4. 고친 뒤 `python3 /tmp/claude-0/-home-user-nurse8/11953438-4bd6-5835-93dd-880b3b9add7a/scratchpad/bank2/check_part.py <묶음 파일>` 을 돌려 형식 오류가 없게 한다.

## 규칙
- 묶음 파일 하나만 직접 고친다. 쓴 사람이 `work-…` 폴더에 남긴 스크립트는 돌리지 않는다(돌리면 네 수정이 덮어써진다). git 명령·빌드·npm test 는 돌리지 않는다.
- 문제가 없는 문제는 건드리지 않는다. 문체를 다듬는 일은 하지 않는다.
